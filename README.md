# 소방관 출동! — 동네를 지키는 소방 뱀서라이크 (시험판 C)

5분 동안 작은 동네 한 블록을 지킨다. 불 괴물이 사방에서 몰려오고, 가게에 불이 나고, 사람이 갇힌다.
호스를 직접 겨눠 불을 끄고, 레벨업 카드로 장비를 모아 4:00에 불타는 창고에서 나오는 화염 거인을 끈다.

```
불 괴물을 끈다 → 경험치 구슬 → 레벨업 카드 3택1 → 더 센 장비
      ↑                                              ↓
 가게에 불(신고) ← 불씨가 건물로 번진다 ← 끄지 않으면 무너진다
      ↓
 문 앞에 서서 갇힌 사람 구조 (경험치·체력 +20)
```

---

## 한 판 (5분)

규칙은 `unity/Assets/Scripts/Prototypes/Logic/SurvivorSim.cs`, 동네 배치는 `SurvivorTown.cs`에 있다.

### 동네
배치는 시드와 상관없이 늘 같다. 소방관이 출발하는 가운데 반경 6칸은 비어 있다.

| 무엇 | 개수 | 비고 |
|---|---|---|
| 가게 | 8채 | 빵집·꽃집·문구점·세탁소·약국·분식집·편의점·이발소. 주민 1~2명씩 |
| 물류창고 | 1채 | 4:00에 보스가 나오는 곳 |
| 가스통 | 3개 | 가게 옆 |
| 나무 · 차 | 8그루 · 5대 | 불이 옮겨붙는다 |

### 불
- **신고**: 10초부터 230초까지 15번, 아직 안 탄 가게 하나에 불이 난다. 2:00와 3:00에는 두 곳이 한꺼번에 탄다.
- **타는 건물**: 불 세기가 점점 커지고, 그만큼 튼튼함이 깎인다. 그대로 두면 약 50초 뒤 무너진다(나무·차는 더 빠르다). 타는 동안 불씨를 뱉어 이웃으로 옮긴다.
- **끄기**: 물을 맞히면 불 세기가 줄고, 0이 되면 꺼진 뒤 10초 동안 젖어 있어 다시 붙지 않는다.
- **가스통**: 불이 붙으면 2.5초 뒤 터진다. 반경 3.5칸의 건물 불을 키우고 불씨를 흩뿌린다. 미리 적셔 두면 붙지 않는다.
- **가장자리 스폰**: 초당 1마리에서 4:00 무렵 8마리까지 늘어난다. 1:00·2:00·3:00에는 사방에서 에워싸는 웨이브가 온다.

| 적 | 체력 | 속도 | 특징 |
|---|---|---|---|
| 불씨 | 2 | 2.4 | 9칸 안의 탈 것으로 가서 불을 옮긴다. 없으면 소방관을 쫓는다 |
| 불덩이 | 14 | 1.5 | 지나간 자리에 타는 바닥을 남긴다 |
| 불똥 | 2 | 4.2 | 빠르게 돌진한다 |
| **화염 거인** (보스) | 1100 | 1.1 | 4:00에 불타는 창고에서 나온다. 끄면 이긴다 |

### 구조
- 가게에 불이 나면 안의 주민이 갇힌다. 창문에 얼굴이 보이고, 문 앞에 초록 고리가 뜬다.
- 문 앞 1.3칸 안에 **1.2초 서 있으면** 한 명을 구한다. 경험치 +20, 체력 +20.
- 불 세기가 0.6 이상인 큰 불 속에서는 15초마다 한 명씩 잃는다. 건물이 무너지면 남은 사람을 모두 잃는다.

### 승패와 별
- **진다**: 체력이 0이 되거나, 가게·창고가 절반 넘게 무너진다(9채 중 5채).
- **이긴다**: 화염 거인을 끈다. 별은 기본 ★1에 더해
  - 지킨 건물 75% 이상이면 ★
  - 잃은 사람이 0명이면 ★

## 레벨업 카드

카드 규칙은 `Logic/SurvivorUpgrades.cs`에 있다.

- 구슬로 경험치를 모은다. 다음 레벨까지 `6 + 5×Lv + Lv²/4`가 필요하다.
- 레벨이 오르면 게임이 멈추고 카드 3장 중 하나를 고른다.
- 무기 칸 4개, 보조 칸 4개가 있고, 각 항목은 Lv5까지 오른다. 처음에는 물대포 하나만 들고 시작한다.
- 더 고를 게 없으면 "응급 처치"(체력 30 회복)가 나온다.

| 종류 | 카드 | 효과 |
|---|---|---|
| 무기 | 물대포 | 겨눈 쪽으로 물줄기를 뿜는다. 레벨마다 굵기·세기 +45%, 사거리 +10% |
| 무기 | 물폭탄 | 불 떼 한가운데 물폭탄을 던진다. 레벨마다 폭탄 +1, 범위 +15% |
| 무기 | 스프링클러 드론 | 주위를 도는 드론이 불을 끈다. 레벨마다 드론 +1 |
| 무기 | 거품 장판 | 지나간 자리에 거품이 남아 불을 늦춘다. 레벨마다 지속 +1초 |
| 보조 | 고압 펌프 | 물줄기가 더 멀리, 더 세게 (+15%) |
| 보조 | 방화복 | 최대 체력 +20, 초당 회복 +0.5. 레벨마다 옷이 바뀐다 |
| 보조 | 장화 | 이동 속도 +10% |
| 보조 | 무전기 | 경험치 끌어오는 범위 +30% |

### 노란 카드 (특수 장비)
레벨 1짜리이고 무기·보조 칸을 쓰지 않는다. **Lv5·10·15…로 오를 때는 반드시 한 장** 나오고, 그 밖의 레벨업에서는 15% 확률로 섞인다.

| 카드 | 효과 |
|---|---|
| 고압 방수포 (진화) | 물대포 Lv5 + 고압 펌프를 갖추면 나온다. 관통하는 물줄기가 사방을 휩쓸고, 손으로 쏘는 물줄기도 관통한다 |
| 소방 헬기 | 9초마다 헬기가 가장 큰 불에 물을 쏟는다 |
| 물의 장막 | 5초마다 몸 주위로 물 고리가 터져 불을 밀어낸다 |
| 구조대원 동료 | 동료가 불난 가게로 달려가 사람을 구한다 |

unity/Assets/Scripts/Prototypes/   시험판 A·B·C

## 실행

### 1. 규칙 테스트 (Unity 불필요)
```bash
brew install dotnet
dotnet test proto-tests
```

### 2. Unity 에디터에서
**준비** (한 번만)
1. `brew install --cask unity-hub`
2. Hub에서 Unity 계정 로그인 → **Personal(무료) 라이선스** 발급
3. 에디터 **6000.3.24f1** 설치 (`unity/ProjectSettings/ProjectVersion.txt`에 고정):
   ```bash
   "/Applications/Unity Hub.app/Contents/MacOS/Unity Hub" -- --headless \
     install --version 6000.3.24f1 --module ios --childModules
   ```
   `--childModules`를 빼면 하위 모듈 설치 여부를 묻는 질문에서 멈춘다. 폰 빌드를 안 할 거면 `--module` 이후는 생략해도 된다.
4. 에디터를 처음 켜면 **Unity 이용약관 동의 창**이 뜬다. 다른 창 뒤에 가려져 멈춘 것처럼 보일 수 있다.

**실행**
```bash
./sync-core.sh
open -a /Applications/Unity/Hub/Editor/6000.3.24f1/Unity.app --args -projectPath "$PWD/unity"
```
메뉴 **FireGame ▸ 시험판 C (뱀서)** 를 고르면 바로 Play 모드로 들어간다. **시험판 C (풀장비)** 는 모든 카드를 최대로 들고 시작한다(연출 확인용).

`core/`를 고쳤다면 `./sync-core.sh`를 다시 실행한다(`unity/Assets/Scripts/Core/`는 사본이라 직접 고치지 않는다).

### 3. 아이폰
```bash
tools/ios-install.sh              # Unity 빌드 → Xcode 서명·빌드 → 설치 → 실행
tools/ios-install.sh --no-unity   # Unity 빌드는 건너뛰고 이미 있는 Xcode 프로젝트로 설치만
```
필요한 것: Unity iOS 모듈, Xcode에 로그인한 개발자 팀, 개발자 모드를 켜고 잠금을 푼 아이폰(USB 또는 같은 와이파이).
폰 빌드에서는 시험판 C가 바로 뜬다. 빌드는 iOS 전용 복사본(`tools/.unity-ios`)에서 돌아서 에디터를 닫을 필요가 없다.

### 4. 검증 도구
```bash
tools/unity-check.sh compile       # 실제 Unity 컴파일. 오류가 있으면 실패
tools/unity-check.sh proto-shots   # 시험판 화면을 tools/.shots-proto/ 에 PNG로 캡처
tools/unity-check.sh ios           # 아이폰용 Xcode 프로젝트만 만든다(unity/Builds/ios)
```

## 밸런스 기준

봇 테스트(`proto-tests/SurvivorTests.cs`)가 보증하는 것:

- 가만히 서 있으면 150초 안에 진다(동네가 타거나 쓰러진다).
- 봇이 시드 10개 중 6개 이상 보스까지 가고, 3~9개를 이긴다(해볼 만하지만 늘 이기지는 않는다).
- 동시에 있는 적은 350을 넘지 않는다.
- 5분 한 판을 시뮬레이션해도 3초 안에 끝난다.
- 같은 시드면 같은 판이다.

## 아직 모르는 것 · 알려진 한계

- **사람이 폰으로 할 때의 난이도**: 봇은 조준이 완벽하다. 두 엄지로 하는 사람의 승률은 해 봐야 안다.
- **카드 밸런스**: 물대포·고압 펌프가 정답 빌드다. 봇 30판 실측에서 보조 카드(거품·장화·무전기·방화복)를 먼저 고르면 한 판도 못 이겼다.
- **판 사이 성장이 없다**: 한 판이 끝나면 남는 것이 없다. 동네도 하나, 보스도 하나다.

## 지난 방향 (참고)

- **캠페인** (`core/`, 메뉴 **FireGame ▸ 본 게임**): 섬마을 지도에서 신고를 받고, 장비를 레벨업해 현장 6곳을 진압하는 게임. 생각 없이 짠 봇이 캠페인 전체를 깨서 고민할 거리가 없었다. 자세한 설명은 커밋 `607b5eb`의 README에 남아 있다.
- **시험판 A** (실시간 물줄기)와 **시험판 B** (턴제 퍼즐): 둘 다 재미 검증에 실패했다. 메뉴에서 여전히 띄울 수 있다.
- 캠페인의 불 등급(나무·기름·전기)과 맞는 약제, 현장 테마 6종은 C의 다음 스테이지 재료로 쓸 수 있다.
